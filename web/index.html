Make it yours

Send /decrumb help, /decrumb status, or /decrumb clean https://… from your phone while Decrumb is running. Only your own commands are accepted. No shell commands or AI.

Removal is optional and affects only notes tracked by this installation. Signal’s removal window is about 24 hours; offline time can prevent removal. Original messages stay untouched.

Advanced cleaning rules

Exact parameter rules per site. “Keep” wins over “remove”. Leave [] to use the built-in rules.

[{"site":"https://example.com","remove":["ref"],"keep":["id"]}]

Changing cleaning rules clears links queued under the old rules.
